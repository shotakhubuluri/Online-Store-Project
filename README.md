# Angular Online Store - Everrest API Integration

პროექტი წარმოადგენს ონლაინ მაღაზიას, რომელიც აგებულია Angular Standalone Architecture-ის გამოყენებით და ინტეგრირებულია `https://api.everrest.educata.dev` API-სთან.

## ფუნქციონალი:
- ავტორიზაცია & რეგისტრაცია
- პროდუქციის გაფილტვრა (კატეგორია, ბრენდი, ფასი, რეიტინგი) და ძებნა დასახელებით
- პაგინაცია (18 პროდუქტი თითო გვერდზე)
- პროდუქტის დეტალური გვერდი (Details და Review ჩანართებით)
- რეიტინგისა და შეფასების დამატების მოდალი
- კალათის სრული მართვა (დამატება, რაოდენობის შეცვლა, წაშლა, ჯამური ფასი)

## ინსტრუქცია პროექტის გასაშვებად:

1. **ZIP არქივის ამოარქივება**:
   ამოაარქივეთ ჩამოტვირთული `angular-online-store.zip` ფაილი თქვენთვის სასურველ საქაღალდეში.

2. **ტერმინალის გახსნა**:
   გახსენით ტერმინალი (Command Prompt / PowerShell / VS Code Terminal) ამ საქაღალდეში.

3. **დამოკიდებულებების (Dependencies) დაყენება**:
   გააშვეთ შემდეგი ბრძანება:
   ```bash
   npm install
   ```

4. **პროექტის გაშვება**:
   წარმატებული ინსტალაციის შემდეგ გააშვეთ:
   ```bash
   npm start
   ```
   ან
   ```bash
   npx ng serve
   ```

5. **საიტის გახსნა ბრაუზერში**:
   გახსენით ბრაუზერი და გადადით მისამართზე: `http://localhost:4200`
